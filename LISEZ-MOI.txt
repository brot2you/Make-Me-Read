MAKE ME READ — VERSION LÉGÈRE POUR GITHUB PAGES

- Contenus et fonctionnalités identiques à la V9.
- 58 couvertures et 58 illustrations intérieures préservées.
- Fichiers JPEG/PNG inutilisés supprimés; illustrations optimisées en WebP.
- Les titres des couvertures et le logo conservent leurs résolutions d'origine.

INSTALLATION
1. Décompresser cette archive.
2. Dans GitHub Desktop, ouvrir le dossier du dépôt Make-Me-Read.
3. Supprimer les anciens fichiers du site (au moins l'ancien dossier assets)
   puis copier index.html, les fichiers JS/CSS et le nouveau dossier assets.
4. Commit to main puis Push origin.

ATTENTION : copier tous les fichiers et sous-dossiers, pas le ZIP lui-même.
N'envoyer que les fichiers réellement contenus dans cette version,
car elle ne contient plus les anciennes images inutilisées.
